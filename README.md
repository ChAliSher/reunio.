# Mila — Smart Lost & Found Platform

Mila is a full-stack web application designed to help people report, discover, and recover lost belongings.

## Features (Planned)

- User registration and authentication
- Report lost and found items
- Upload item images
- Search and filter listings
- Smart lost-and-found matching
- Ownership verification
- Real-time notifications

## Tech Stack

**Frontend:** Next.js, React, TypeScript, Tailwind CSS

**Backend:** NestJS, Node.js, TypeScript

**Database:** PostgreSQL, Prisma ORM

**Future Integrations:** Socket.IO, Cloudinary

## Project Structure

- `frontend/` — User-facing web application
- `backend/` — REST API and business logic
- `docs/` — Architecture and technical documentation

## Project Status

Phase 1 — Initial setup and repository configuration.

## Goal

Make recovering lost belongings easier, faster, and more secure, starting with university communities.
